## Introduction

Navigating the data job market can often feel like a maze. This upgraded dashboard (v2) is built specifically for **Job Seekers, Career Transitioners, and Data Professionals** to cut through the noise. Powered by a real-world dataset of 2024 data science job postings—featuring detailed titles, salaries, and locations—this project delivers a sleek, single-page interface designed for instant access to critical market trends and compensation insights.

## Skills Showcased

This project translates raw data into actionable intelligence by leveraging key Power BI capabilities. Here are the core technical skills demonstrated:

*   **🎨 UI/UX Design:** Crafted an intuitive, highly visual, and user-centric report layout.
*   **⚙️ Power Query (ETL):** Executed robust data cleaning, shaping, and transformation to prepare raw datasets for analysis.
*   **🔗 Data Modeling:** Architected efficient relational data models utilizing Star Schema principles.
*   **🧮 DAX Fundamentals:** Engineered custom formulas and aggregations to uncover deep analytical insights.
*   **📊 Dynamic Visualizations:**
    *   **📈 Core Charts:** Deployed Column, Bar, Line, and Area charts to accurately map trends and comparisons.
    *   **🗺️ Geospatial Maps:** Visualized the global distribution of job opportunities.
    *   **🔢 KPI Cards:** Highlighted critical, top-line performance indicators for immediate visibility.
    *   **📋 Granular Tables:** Provided structured, detailed views of the underlying data.
*   **🖱️ App-Like Interactivity:**
    *   **🎚️ Slicers:** Enabled seamless, dynamic filtering for a personalized user experience.
    *   **🔘 Buttons & Bookmarks:** Engineered fluid navigation and state management across the dashboard.
*   **🎛️ Advanced Field Parameters:**
    *   **Dynamic Metric Switching:** Implemented Field Parameters to allow users to toggle between different measures within a single visual (e.g., switching between **Job Count** and **Job Percent**, or **Median Yearly** vs. **Hourly Salary**).
    *   **Enhanced User Autonomy:** Designed a custom slicer interface (button-style) that enables on-the-fly analytical pivots, reducing dashboard clutter while maximizing insight depth.

## Dashboard Overview (Version 2 - Single Page Focus)

This second iteration optimizes the user experience by consolidating everything into a **single, highly-focused page**, putting the most valuable market insights right at your fingertips.

![Data Jobs Dashboard v2.0](../images/page_1_v2.png) 

Think of this page as your personal mission control for the data job market. It immediately highlights vital metrics—such as **Total Job Count, Average Skills Per Job, and Median Salaries (Yearly & Hourly)**. Additionally, users can instantly analyze **Skill Popularity** and compare **Compensation across diverse Job Titles**, all within one seamless and efficient view.
